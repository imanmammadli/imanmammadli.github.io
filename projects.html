Real-Time Ride Analytics Platform

This Real-Time Data Pipeline project, built for Uber/Bolt-style ride-hailing platforms, processes incoming ride events as a data stream. Using Kafka and Spark Streaming, the data is sent to PostgreSQL in real time to power live dashboards, while simultaneously being transformed via S3/MinIO and dbt to land in the BigQuery Data Warehouse. Finally, analytics are visualized using Power BI or Tableau. Based on a professional Lambda/Kappa architecture, this end-to-end system showcases my core data engineering skills.
